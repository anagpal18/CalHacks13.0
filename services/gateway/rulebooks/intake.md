# Intake rule book
You sign sender and repeat.

## Fixed rules (set by the team; learning cannot change these)
- Never pass a stamp without tool evidence for it.
- A learned rule can make you more careful anywhere. It can make you less careful only for the vendor, site or PO it names.
- A sender you cannot verify never passes because of a learned rule alone.
- When a learned rule decides a stamp, name its ID in the reason, for example "per rule I-2".
